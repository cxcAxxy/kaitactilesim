## 45° 白板：场景、接触物理与专家动作

以下介绍 45° 原任务。水平变体的场景、控制目标和回位差异见后续分节。

独立任务 `whiteboard-wipe`。桌面上有相对水平面倾斜 45°、朝向机器人的白板，板面初始为 **高 14 cm、宽 16 cm 的黑色 Z 字**，覆盖范围与原两条横线相同。右手从桌面抓起白板擦，把黑色毛毡底面贴向白板，按**上横线 → 向下斜线 → 下横线**的顺序受力滑动、渐渐擦除笔迹，然后放回桌面、松手并撤离。

底层场景/专家入口为 `scripts/workcell/view_whiteboard_wipe.py`，样例录制入口为 `scripts/workcell/record_whiteboard_example.py`。

笔迹保留 25 个独立清洁单元及原有记录维度，上横线、斜线、下横线分别由 8、9、8 段连续细笔画组成。长笔画完整落在毛毡覆盖范围内后，才累计实际摩擦功、滑动距离和加载时间；1.5 N 最低载荷及切向载荷、速度、摩擦功、距离和时间门槛保持不变，8 N 只作为正式评估安全/分布外阈值，不作为擦除有效性上限。深度控制使用 2.2 N 目标，并在载荷升高时暂缓擦拭路径。Z 字布局版本为 `z_top_down_v1`，记录于 `ink_randomization.pattern`；旧两横线数据和 checkpoint 不会自动变成 Z 字任务，需重新采集、训练和评估。

```bash
pixi run --as-is view-whiteboard-wipe
pixi run --as-is run-whiteboard-wipe
pixi run --as-is run-whiteboard-wipe --camera head
pixi run --as-is run-whiteboard-wipe --headless
```

### 外形与场景隔离

白板为 36×40 cm，铝色边框和桌面支架固定于世界。板擦参考白色塑料壳、黑色毛毡底的桌面板擦：名义尺寸 **115×56×30 mm**，毛毡底 **111×52×6 mm**，白壳带圆角、浅纵向防滑纹及无字光面标签区。总质量 **80 g**；顶部装饰比名义外壳高约 0.18 mm。板擦初始绕世界 Z 轴转 +90°，平放于桌面。双臂从 shared 对称收臂姿势开始，右手张开并连续运动至板擦上方。

`eraser_handle` 是白色外壳碰撞体，`eraser_pad` 是黑色毛毡碰撞体；两者各为一个凸圆角网格。防滑纹和标签只参与显示。外形可用以下命令重建，网格内嵌在本任务的 `scene.xml` 中：

```bash
pixi run --as-is python -m kaihand_tactile_env.tasks.whiteboard_wipe.geometry
```

代码和资产位于 `src/kaihand_tactile_env/tasks/whiteboard_wipe/`。场景直接 include `shared/mjcf/robot.xml` 与 `control.xml`，复用双臂、KaiHand、HEAD 和双腕相机的安装与标定；另有验收相机 `board_overview`。执行器以共享配置为基础，仅在本任务模型中调整右手速度伺服增益。触觉复用 shared 的 `SolverDistributedTactileProvider`，将实际指腹接触力守恒分配到每指 7×5 触元，单位 N。

外形、抓取、白板接触和清洁参数都属于该任务。已有任务的场景、机器人 MJCF、共享相机标定和触觉算法保持不变；1 ms 物理步长与控制设置只作用于本任务创建的模型。

### 板擦与白板的摩擦

`scene.xml` 显式定义接触对 `eraser_board_contact`，关联 `eraser_pad` 和 `board_surface`：

```xml
<pair name="eraser_board_contact" geom1="eraser_pad" geom2="board_surface"
      condim="6" friction=".65 .65 .003 .0003 .0003"
      solref=".09 1" solimp="0 .95 .001 .5 2" margin="0" />
```

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| 两个切向滑动摩擦系数 | 0.65、0.65 | 两个板面方向一致，无量纲 |
| 扭转摩擦系数 | 0.003 m | 绕接触法线的旋转阻力参数 |
| 两个滚动摩擦系数 | 0.0003 m、0.0003 m | 绕接触切向轴的旋转阻力参数 |
| `condim` | 6 | 法向、切向及扭转/滚动接触约束 |
| `solref` | 0.09 s、1 | 毛毡软接触时间常数、阻尼比；按软毛毡接触延长时间常数，抑制接触建立时的瞬时法向尖峰 |
| `solimp` | 0、0.95、0.001 m、0.5、2 | 接触阻抗从零开始，随约束距离平滑建立 |
| `margin` | 0 | 不膨胀碰撞表面，使用原生多点接触生成 |
| 本任务模型的 `impratio` | 10 | 摩擦约束相对法向约束的阻抗比例 |
| 本任务模型的 `ccd_tolerance` | 1e-10 m | 凸碰撞检测的距离收敛容差 |
| 本任务模型的 `ccd_iterations` | 100 | 凸碰撞检测的最大迭代次数 |

显式 `pair` 直接决定这两个几何体之间的接触参数，不再由各自 geom 参数混合推导。`solref` 的正数格式表示时间常数与阻尼比。参数含义见 [MuJoCo 官方接触参数说明](https://mujoco.readthedocs.io/en/stable/modeling.html#contact-parameters)。

μ=0.65 规定摩擦约束，实际摩擦力由求解器根据法向载荷与接触运动求出。控制器擦拭时的板面法向力目标是 **2.2 N**；下述清洁判断使用实际求解器载荷和实际滑动，不使用目标力代替测量。白壳和毛毡目前都是刚体几何，接触柔顺性由 MuJoCo 软接触近似，没有模拟独立纤维、毛毡体积压缩或墨水化学。

板面接触保留起始阻抗为零的 `solimp`，使承力平滑建立；`impratio=10` 减少摩擦软约束造成的持续手内漂移。白壳滑动摩擦系数仍为 **1.2**，毛毡–白板滑动摩擦系数仍为 **0.65**，没有通过增大摩擦系数、改变形状或质量来压低力曲线。

#### 接触点与高频力波动的修正

前一版虽然改善了板面法向承力通断，抓取、擦拭和放下的原始指尖力仍有密集尖峰。进一步审计发现，指尖碰撞位置和法向可以基本稳定，毛毡–白板接触的受力中心却在相邻 **2 ms** 内跳动，最坏约 **27 mm**，同时向板擦施加变化的力矩。只检查总法向载荷或手指接触数量，会漏掉这个问题。

原来的白壳、毛毡及毛毡–白板显式接触对均使用正的 **0.2 mm margin**。在当前 MuJoCo 的凸网格碰撞中，正 margin 会让多点接触生成使用微旋转后重复碰撞检测的路径；对接近平行的平面，生成的接触点集合及其分担载荷可能随微小姿态变化跳变。现在将 `eraser_handle`、`eraser_pad` 和 `eraser_board_contact` 的 margin 全部设为 **0**，使板擦与手指、桌面、白板的相关接触使用原生多点生成，并将本任务的 CCD 容差设为 **1e-10 m**、最大迭代次数设为 **100**。碰撞网格、质量和摩擦系数保持原值。对应算法与 margin 条件见 [MuJoCo 官方多点接触说明](https://mujoco.readthedocs.io/en/latest/computation/#multiple-contacts)。

对照试验中，仅将白壳 margin 归零能改善搬运段，但仍留下毛毡接触白板、桌面时的切向力抖动；继续将显式板面接触对和毛毡 geom 的 margin 归零，才同时改善擦拭及抓取、放下阶段。另一个已落实的修正是下文的右手伺服增益与目标插值。

### 需要受力滑动才会擦除

笔迹分成 25 个局部单元，规则实现在 `task.py` 和 `cleaning.py`。只有擦垫与白板的真实接触参与清洁。每个物理步先判断笔迹单元是否处于擦垫底面覆盖范围：板擦局部 `|x| < 53 mm`、`|y| < 24 mm`，且与底面 `z=-15 mm` 的距离小于 2 mm。

每个求解器接触点的切向力大小，以及耗散功率 `max(0, -F_t · v_t)`，按接触点到被覆盖笔迹单元的距离分配；距离权重采用尺度为 28 mm 的高斯函数。每个接触点的分配权重总和不超过 1，避免同一份摩擦功重复计入多个单元。滑动速度来自刚体实际线速度与角速度在接触点处的合成，并投影到板面；单元速度按其切向载荷加权。

单元需要同时满足以下条件才累计清洁量：

- 擦垫–白板实际法向总载荷至少 **1.5 N**，清洁累计不设法向力上限；
- 分配到该单元的实际切向载荷至少 **0.02 N**；
- 该单元实际滑动速度 **5–150 mm/s**，含上下限；
- 分配到该单元的耗散摩擦功率大于 0。

**8 N 是正式评估的安全/分布外 guard，不是材料擦除上限。** 真实板擦的受力滑动不会在越过一个人为评估阈值时突然停止擦除，因此仿真在超过 8 N 后仍按擦垫–白板接触产生的实际摩擦功、滑动距离和加载时间累计。正式评估仍会在 `>8 N` 时以 `force_guard` 终止；只有显式诊断模式会记录超限后继续运行，而且结果标记为 `diagnostic_only`、`formal_metrics_valid=false`，不能混入正式成功率。

满足门槛期间，累计该单元的摩擦功、有效滑动距离和有效加载时间。完成比例取三者中最小的归一化进度：

```text
progress = clip(min(work / 1 mJ, stroke / 30 mm, loaded_time / 0.25 s), 0, 1)
remaining = 1 - progress
```

因此每个单元必须同时积累 **1 mJ 摩擦功、30 mm 有效滑动和 0.25 s 有效加载时间**才会完全擦净；分次经过可以累积。超过 8 N 也不会自动擦净，仍须满足上述切向载荷、速度、正耗散功、行程和时间条件。笔迹透明度为 `sqrt(remaining)`，会逐渐变淡。轻触、静压、悬空划过、无摩擦滑动及短促撞击都无法直接擦净；手指或白壳接触板面不贡献清洁进度。

这是一组未经材料实验标定的仿真任务参数。局部载荷分配、覆盖范围与渐隐规则用于近似“需要稍微用力、持续擦动才能清洁”的行为，不代表特定品牌板擦或墨水的实测性能；模型也没有描述过大压力造成的毛毡压缩、磨损或板面损伤，所以超限继续累计只用于避免“力越大反而停止擦除”的非物理跳变，并不表示高压操作安全。

### 抓取与执行

板擦保持自由刚体状态。reset 设置初始状态后，执行期间通过机械臂、手指执行器和真实摩擦接触搬运，不使用工具焊接约束、物体瞬移或直接施加到板擦的外力。机器人确认拇指与其余手指形成对握后才提起，放回时先确认桌面支撑，再松手、撤离并检查稳定性。

执行器使用已知场景位置和仿真工具姿态反馈。抓紧阶段由五指触觉建立对握；验证抓取后保持该组手指位置目标，避免把板面接触的高频变化反馈成新的握持指令。实际板面法向力反馈只调节贴板深度。物理与清洁更新为 **1000 Hz**，通用控制目标为 **100 Hz**，擦板接触控制为 **200 Hz（5 ms）**；机械臂和手指的新位置目标在控制周期内线性插值，机械臂保留关节速度限制。插值只作用于执行器命令，记录的实际接触力不做滤波、限幅或插值。

初始预抓取固定使用腕部第 5 关节的负角度 IK 解支，从 shared home 用 5 s 接近板擦上方。
七个关节采用端点速度为零的五次插值；抓起并抬离桌面后，再用 5 s 五次关节轨迹展开肩、肘和腕部到白板前。
运行时拒绝错误旋转方向、过高速度、过高加速度或不可达解支。旧轨迹对比与单次速度/加速度实测见
[历史记录](../archive/task_scene_history.md#whiteboard-2026-09)。

擦拭时保持 **2.2 N** 的板面法向力目标，每 **5 ms** 使用上一小段物理接触力均值及上升趋势调节深度。搬运先使用固定短解支到板前，保持约 **7 cm** 法向间隙，以 **4 s** 笛卡尔路径移至 Z 字上方，再用 **1.5 s** 接近。载荷目标采用名义 **2 s** 平滑斜坡，实际载荷达到 **1.8 N** 后才开始擦拭；加载超过 **8 s** 未建立预载则报错退出。三笔名义时间为 **5.5 / 6.5 / 5.5 s**，各段使用端点速度为零的五次插值；实际时间可因超载减速延长。板面局部 x 轴指向上方，因此三笔的 x 从 +7 cm 到 −7 cm，不随随机 y 正负翻转。接触控制的逆运动学位置容差为 **0.001 mm**。笔迹清除仍依赖实际受力滑动，此处控制反馈不改变原始触觉记录。

切向路径时钟根据实测板面载荷减速：超过目标 **0.2 N** 开始减速、超过目标 **0.5 N** 请求暂停。时钟速度比例的变化率限制为 **2 s⁻¹**，避免带载运动反复急停、起步引起的短时力波动；这只平滑控制命令，不平滑实测力。法向控制仍使用力上升趋势预测卸载，不将该预测值直接用于切向启停。随机位置靠近边框时，仅缩短首尾引入/引出距离，Z 字本身的尺寸不变。

本任务将右手速度执行器增益 `kv` 从共享默认值 **30** 调整到 **1**，位置外环增益仍为 **24 s⁻¹**，原速度范围和关节力矩限制保留。这样降低了闭环位置误差产生的力矩增益，配合手指目标插值，减小抓取和释放时的控制激励。修改作用于本任务实例化的 `MjModel`，不回写共享控制 XML，也不改变其他环境的手指参数。这是已知状态演示控制器，尚未实现基于 RGB 的笔迹识别或视觉闭环。

放回时先移动到原放置位置上方约 **3 mm**，再以 **2 mm/s** 的腕部下降指令接近桌面；测得桌面支撑力达到 **0.20 N** 后停止固定下降，继续保持抓取闭合位置。随后通过竖直位置反馈把实际桌面支撑力调到板擦自重（80 g，约 **0.785 N**），消除手向桌面施加的额外压力。开始松手前必须确认桌面已承接重量；松手全过程继续此载荷反馈。

释放时用每根手指的实测法向力反馈，令五指的目标载荷在 **1.5 s** 内平滑降到零，并继续跟踪 **1 s**，最后再用 **1 s** 完全张开。这能减小其余手指已脱离、拇指仍夹紧并向桌面下压的支撑转移尖峰。桌面支撑和释放的逆运动学位置容差收紧为 **0.001 mm**，使微小的卸载指令及时执行。触觉切向力定义在指腹局部坐标系，板面或桌面法向反力也可能落在该指腹的切向平面；它不等于板擦与白板之间的摩擦力。

原生及专家完整成功的差异统一见[成功判定](success_criteria.md#whiteboard-wipe)。单次专家演示不能作为随机场景成功率。

这些修正针对仿真接触与控制的数值问题。接触建立、滑动转向、支撑转移和松手仍会改变实际受力；验收同时检查原始力、接触受力中心和实际运动，而不以曲线越平越好作为目标。没有材料实验和真实传感器对照，仿真剩余变化不能直接解释为真实板擦的摩擦振动或触觉噪声。

结果中的执行器指尖峰值按控制器统计，板面峰值按 **1000 Hz** 物理更新统计；示例力分析使用共享 Raw 中未滤波的 **100 Hz** 求解器触觉。清洁每 **1 ms** 更新。完整物理回归仍检查 1000 Hz 接触过程，不能只凭 100 Hz 曲线断言更高频的接触动力学已经收敛。

```bash
PYTHONPATH=src .pixi/envs/default/bin/python -B scripts/workcell/compare_whiteboard_contact_intensity.py \
  --trial-dir /path/to/existing/seed_001 \
  --output-dir /new/path/seed_001_contact_preview \
  --demo-root "$PWD/task_demo" --preview
```

该离线命令可加 `--reference-hdf5 /path/to/expert/episode.h5` 覆盖示例参考。历史日志缺少
瞬时板擦接触力或抓握对象分类时，只展示有证据的字段；累计任务峰值单列，不能当成逐步轨迹。
清洁进度只从历史逐步日志中的真实记录恢复；如果只有终态比例，保留终态读数并标注进度
曲线缺失。历史预览不会改写旧 `summary.json`、原视频或已有评估结果。

### 按专家时间线的指尖空间触觉预览

除总接触力外，已有白板评估可另生成中文“指尖触觉接触对比”。参考固定来自
`task_demo` 对应任务的成功专家原始 HDF5，保留专家物理时间线；模型使用自己实际
经过的仿真时间，早停之后留空，不补零、不拉伸。此命令仅做离线诊断，不修改评估
结果或运行仿真，也不默认加入新评估的 `summary.json`。

```bash
PYTHONPATH=src .pixi/envs/default/bin/python -B scripts/workcell/compare_whiteboard_tactile.py \
  --trial-dir /path/to/existing/seed_001 \
  --demo-root "$PWD/task_demo" \
  --snapshot-times-s 20.0 28.3 34.0
```

默认在该 trial 根目录另存五个文件，已有同名文件时拒绝覆盖，可用 `--output-dir`
指定新的目录。`--snapshot-times-s` 是三个专家仿真时间，可省略，由专家接触阶段
自动选取；`--contact-threshold-n` 默认 `0.05 N`，不是新增的安全阈值。

| 文件 | 内容 |
|---|---|
| `tactile_contact_timeline.png` | 五指法向力与净切向力、双方有接触时的局部中心偏差和归一化空间分布差异；标注漏接触、额外接触、数据缺失和早停 |
| `tactile_contact_centers.png` | 指尖固定局部坐标中的受力中心轨迹与分布 |
| `tactile_contact_heatmaps.png` | 三个快照的专家／模型／差值 7×5 法向力网格；共用实际力值色标，白圈标注法向力加权的行列网格中心 |
| `tactile_contact_comparison.json` | 时间、数据来源、坐标核验、有效覆盖和逐指统计，说明使用限制 |
| `tactile_contact_comparison.npz` | 原生网格及派生数据，可独立复核 |

受力中心按法向力加权，以指尖局部毫米坐标表示，避免整只手运动污染指标。
归一化网格先除以每指总法向力，再比较空间分布；因此总力变大与接触形状变化分开
阅读。无接触时中心未定义，不放到网格原点；中心／形状偏差仅在双方有接触时计算，
并同时报告接触状态不一致，不能通过忽略漏接触得到好看的平均偏差。

专家和模型原生采样频率分别标注。时间配对只使用最新且未过期的非未来模型样本，
模型早停后和采样缺口处不生成配对结果；同一秒的差异还包含动作进度不同，不能全部
解释为接触质量差。切向网格保留有符号分量，合力幅值不等于不抵消的切向载荷。

历史 NPZ 没保存局部坐标时，只在冻结部署的网格与坐标生成代码哈希核验通过，且与
专家坐标匹配后才恢复毫米坐标；核验不通过则拒绝生成，不能静默使用当前布局。
当前网格是 solver 接触力经归一化高斯核分配的空间估计，单位为 `N/taxel`，不是
柔性皮肤压力真值。指尖图用于解释抓持，清洁进度与板擦—白板接触仍单独评价。

### 五指整体触觉变化概览

已有评估还可生成“圆＋箭头”的整体变化预览，与逐格阵列图配套阅读：圆的位置为
法向力加权受力中心，圆面积表示当前每指总法向力，圆颜色表示固定时间窗口内的
法向力增减，箭头方向和长度表示切向力变化向量 `ΔFt`。箭头不是当前受力方向，也
不是受力中心的移动方向；它的长度单位为 N，不是 N/s。圈是力值示意，不是真实
接触面积，不能把它当作柔性皮肤压力图。

```bash
PYTHONPATH=src .pixi/envs/default/bin/python -B scripts/workcell/preview_whiteboard_tactile_glyphs.py \
  --trial-dir /path/to/existing/seed_001 \
  --snapshot-times-s 20.0 28.5 34.0 \
  --window-s 0.1
```

另存 `tactile_overall_change.png`、`tactile_overall_change.mp4`、
`tactile_overall_change.json` 和 `tactile_overall_change.npz`，已有同名文件拒绝覆盖。
可用 `--output-dir` 另存；`--no-video` 只生成静态图及数据。视频由已记录触觉数据绘制，
不是再次运行模型或重新录制仿真相机，也不修改原 `summary.json`、视频及阵列报告。

专家在上排、模型在下排，五指固定列，固定使用专家物理时间线。默认变化窗口为
`0.1 s`，两边都按 `t` 和 `t−0.1 s` 配对，而不是各自减上一帧。默认每 `0.1` 仿真秒
显示一帧，播放按相同时间比例进行；跨越缺失数据或大采样缺口的变化不计算，模型
结束后留空。无接触、变化未知和未观测分别标注，未知中心不放到指尖原点。

所有指尖、两条轨迹和全部时刻使用相同圆面积、箭头长度和颜色尺度。若箭头为避免
遮挡而设置固定显示上限，超过上限时必须注明截断并显示实际变化量；真实数据在
JSON/NPZ 中保留，不随图形截断。净切向力可能抵消，因此短箭头不证明各个触觉
单元都没有切向变化，仍需结合阵列图和真实清洁进度判断。
