# 45° 白板擦拭

独立任务 `whiteboard-wipe`。桌面上有相对水平面倾斜 45°、朝向机器人的白板，板面初始有约 **14×16 cm 的两条黑色笔迹**，两条中心间距约 **14 cm**。右手从桌面抓起白板擦，把黑色毛毡底面贴向白板，逐条受力滑动、渐渐擦除笔迹，然后放回桌面、松手并撤离。

笔迹保留 25 个独立清洁单元及原有记录维度，两条分别由 12、13 段连续细笔画组成。长笔画完整落在毛毡覆盖范围内后，才累计实际摩擦功、滑动距离和加载时间；清洁门槛保持不变。换条时先卸载，再离板横移并快速接近下一条；接触载荷在板擦已经沿笔迹方向运动时建立，取消原先长时间原地等待。深度控制使用 2.2 N 目标，并在载荷升高时暂缓擦拭路径。相机、触觉配置、观测/动作维度和数据格式不变；轨迹分布和软接触参数已经变化，旧模型表现需要另行评估。

```bash
pixi run view-whiteboard-wipe
pixi run run-whiteboard-wipe
pixi run run-whiteboard-wipe --camera head
pixi run run-whiteboard-wipe --headless
```

## 外形与场景隔离

白板为 36×40 cm，铝色边框和桌面支架固定于世界。板擦参考白色塑料壳、黑色毛毡底的桌面板擦：名义尺寸 **115×56×30 mm**，毛毡底 **111×52×6 mm**，白壳带圆角、浅纵向防滑纹及无字光面标签区。总质量 **80 g**；顶部装饰比名义外壳高约 0.18 mm。板擦初始绕世界 Z 轴转 +90°，平放于桌面。双臂从 shared 对称收臂姿势开始，右手张开并连续运动至板擦上方。

`eraser_handle` 是白色外壳碰撞体，`eraser_pad` 是黑色毛毡碰撞体；两者各为一个凸圆角网格。防滑纹和标签只参与显示。外形可用以下命令重建，网格内嵌在本任务的 `scene.xml` 中：

```bash
pixi run python -m kaihand_tactile_env.tasks.whiteboard_wipe.geometry
```

代码和资产位于 `src/kaihand_tactile_env/tasks/whiteboard_wipe/`。场景直接 include `shared/mjcf/robot.xml` 与 `control.xml`，复用双臂、KaiHand、HEAD 和双腕相机的安装与标定；另有验收相机 `board_overview`。执行器以共享配置为基础，仅在本任务模型中调整右手速度伺服增益。触觉复用 shared 的 `SolverDistributedTactileProvider`，将实际指腹接触力守恒分配到每指 7×5 触元，单位 N。

外形、抓取、白板接触和清洁参数都属于该任务。已有任务的场景、机器人 MJCF、共享相机标定和触觉算法保持不变；1 ms 物理步长与控制设置只作用于本任务创建的模型。

## 板擦与白板的摩擦

`scene.xml` 显式定义接触对 `eraser_board_contact`，关联 `eraser_pad` 和 `board_surface`：

```xml
<pair name="eraser_board_contact" geom1="eraser_pad" geom2="board_surface"
      condim="6" friction=".65 .65 .003 .0003 .0003"
      solref=".09 1" solimp="0 .95 .001 .5 2" margin="0" />
```

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| 两个切向滑动摩擦系数 | 0.65、0.65 | 两个板面方向一致，无量纲 |
| 扭转摩擦系数 | 0.003 m | 绕接触法线的旋转阻力参数 |
| 两个滚动摩擦系数 | 0.0003 m、0.0003 m | 绕接触切向轴的旋转阻力参数 |
| `condim` | 6 | 法向、切向及扭转/滚动接触约束 |
| `solref` | 0.09 s、1 | 毛毡软接触时间常数、阻尼比；按软毛毡接触延长时间常数，抑制接触建立时的瞬时法向尖峰 |
| `solimp` | 0、0.95、0.001 m、0.5、2 | 接触阻抗从零开始，随约束距离平滑建立 |
| `margin` | 0 | 不膨胀碰撞表面，使用原生多点接触生成 |
| 本任务模型的 `impratio` | 10 | 摩擦约束相对法向约束的阻抗比例 |
| 本任务模型的 `ccd_tolerance` | 1e-10 m | 凸碰撞检测的距离收敛容差 |
| 本任务模型的 `ccd_iterations` | 100 | 凸碰撞检测的最大迭代次数 |

显式 `pair` 直接决定这两个几何体之间的接触参数，不再由各自 geom 参数混合推导。`solref` 的正数格式表示时间常数与阻尼比。参数含义见 [MuJoCo 官方接触参数说明](https://mujoco.readthedocs.io/en/stable/modeling.html#contact-parameters)。

μ=0.65 规定摩擦约束，实际摩擦力由求解器根据法向载荷与接触运动求出。控制器擦拭时的板面法向力目标是 **2.2 N**；下述清洁判断使用实际求解器载荷和实际滑动，不使用目标力代替测量。白壳和毛毡目前都是刚体几何，接触柔顺性由 MuJoCo 软接触近似，没有模拟独立纤维、毛毡体积压缩或墨水化学。

板面接触保留起始阻抗为零的 `solimp`，使承力平滑建立；`impratio=10` 减少摩擦软约束造成的持续手内漂移。白壳滑动摩擦系数仍为 **1.2**，毛毡–白板滑动摩擦系数仍为 **0.65**，没有通过增大摩擦系数、改变形状或质量来压低力曲线。

### 接触点与高频力波动的修正

前一版虽然改善了板面法向承力通断，抓取、擦拭和放下的原始指尖力仍有密集尖峰。进一步审计发现，指尖碰撞位置和法向可以基本稳定，毛毡–白板接触的受力中心却在相邻 **2 ms** 内跳动，最坏约 **27 mm**，同时向板擦施加变化的力矩。只检查总法向载荷或手指接触数量，会漏掉这个问题。

原来的白壳、毛毡及毛毡–白板显式接触对均使用正的 **0.2 mm margin**。在当前 MuJoCo 的凸网格碰撞中，正 margin 会让多点接触生成使用微旋转后重复碰撞检测的路径；对接近平行的平面，生成的接触点集合及其分担载荷可能随微小姿态变化跳变。现在将 `eraser_handle`、`eraser_pad` 和 `eraser_board_contact` 的 margin 全部设为 **0**，使板擦与手指、桌面、白板的相关接触使用原生多点生成，并将本任务的 CCD 容差设为 **1e-10 m**、最大迭代次数设为 **100**。碰撞网格、质量和摩擦系数保持原值。对应算法与 margin 条件见 [MuJoCo 官方多点接触说明](https://mujoco.readthedocs.io/en/latest/computation/#multiple-contacts)。

对照试验中，仅将白壳 margin 归零能改善搬运段，但仍留下毛毡接触白板、桌面时的切向力抖动；继续将显式板面接触对和毛毡 geom 的 margin 归零，才同时改善擦拭及抓取、放下阶段。另一个已落实的修正是下文的右手伺服增益与目标插值。

## 需要受力滑动才会擦除

笔迹分成 25 个局部单元，规则实现在 `task.py` 和 `cleaning.py`。只有擦垫与白板的真实接触参与清洁。每个物理步先判断笔迹单元是否处于擦垫底面覆盖范围：板擦局部 `|x| < 53 mm`、`|y| < 24 mm`，且与底面 `z=-15 mm` 的距离小于 2 mm。

每个求解器接触点的切向力大小，以及耗散功率 `max(0, -F_t · v_t)`，按接触点到被覆盖笔迹单元的距离分配；距离权重采用尺度为 28 mm 的高斯函数。每个接触点的分配权重总和不超过 1，避免同一份摩擦功重复计入多个单元。滑动速度来自刚体实际线速度与角速度在接触点处的合成，并投影到板面；单元速度按其切向载荷加权。

单元需要同时满足以下条件才累计清洁量：

- 擦垫–白板实际法向总载荷 **1.5–8 N**，含上下限；
- 分配到该单元的实际切向载荷至少 **0.02 N**；
- 该单元实际滑动速度 **5–150 mm/s**，含上下限；
- 分配到该单元的耗散摩擦功率大于 0。

满足门槛期间，累计该单元的摩擦功、有效滑动距离和有效加载时间。完成比例取三者中最小的归一化进度：

```text
progress = clip(min(work / 1 mJ, stroke / 30 mm, loaded_time / 0.25 s), 0, 1)
remaining = 1 - progress
```

因此每个单元必须同时积累 **1 mJ 摩擦功、30 mm 有效滑动和 0.25 s 有效加载时间**才会完全擦净；分次经过可以累积。笔迹透明度为 `sqrt(remaining)`，会逐渐变淡。轻触、静压、悬空划过、无摩擦滑动及短促撞击都无法直接擦净；手指或白壳接触板面不贡献清洁进度。

这是一组未经材料实验标定的仿真任务参数。局部载荷分配、覆盖范围与渐隐规则用于近似“需要稍微用力、持续擦动才能清洁”的行为，不代表特定品牌板擦或墨水的实测性能。

## 抓取与执行

板擦保持自由刚体状态。reset 设置初始状态后，执行期间通过机械臂、手指执行器和真实摩擦接触搬运，不使用工具焊接约束、物体瞬移或直接施加到板擦的外力。机器人确认拇指与其余手指形成对握后才提起，放回时先确认桌面支撑，再松手、撤离并检查稳定性。

执行器使用已知场景位置和仿真工具姿态反馈。抓紧阶段由五指触觉建立对握；验证抓取后保持该组手指位置目标，避免把板面接触的高频变化反馈成新的握持指令。实际板面法向力反馈只调节贴板深度。物理与清洁更新为 **1000 Hz**，通用控制目标为 **100 Hz**，擦板接触控制为 **200 Hz（5 ms）**；机械臂和手指的新位置目标在控制周期内线性插值，机械臂保留关节速度限制。插值只作用于执行器命令，记录的实际接触力不做滤波、限幅或插值。

初始预抓取固定使用腕部第 5 关节的负角度 IK 解支：从 shared home 到板擦上方的整个 5 s 接近中，该关节净转动 **−12.95°**，不再从 −150° 绕到 +146°。七个关节采用端点速度为零的五次插值；本次实测最大关节速度 **48.45°/s**、最大加速度 **67.17°/s²**。抓起后先抬离桌面，再用 5 s 五次关节轨迹连续展开肩、肘和腕部到白板前；该段最大速度 **61.49°/s**、最大加速度 **37.83°/s²**。运行时会直接拒绝错误旋转方向、过高速度、过高加速度或不可达解支。

擦拭时保持 **2.2 N** 的板面法向力目标，每 **5 ms** 使用上一小段物理接触力均值及上升趋势调节深度。每个 20 cm 中心轨迹的名义时间为 **5.5 s**；板擦从距板约 0.5 mm 处开始沿轨迹运动，前半段建立载荷并标记为 `load_board`，载荷稳定后的后半段标记为 `wipe`。两条之间依次执行 **0.8 s** 卸载、**2.5 s** 离板横移和 **0.8 s** 接近，不再原地预加载等待。过载减速只作用于实际擦板轨迹，不会拖慢离板换条过程。接触控制的逆运动学位置容差为 **0.01 mm**。笔迹清除仍依赖实际受力滑动，此处控制反馈不改变原始触觉记录。

本任务将右手速度执行器增益 `kv` 从共享默认值 **30** 调整到 **1**，位置外环增益仍为 **24 s⁻¹**，原速度范围和关节力矩限制保留。这样降低了闭环位置误差产生的力矩增益，配合手指目标插值，减小抓取和释放时的控制激励。修改作用于本任务实例化的 `MjModel`，不回写共享控制 XML，也不改变其他环境的手指参数。这是已知状态演示控制器，尚未实现基于 RGB 的笔迹识别或视觉闭环。

放回时先移动到原放置位置上方约 **3 mm**，再以 **2 mm/s** 的腕部下降指令接近桌面；测得桌面支撑力达到 **0.20 N** 后停止固定下降，继续保持抓取闭合位置。随后通过竖直位置反馈把实际桌面支撑力调到板擦自重（80 g，约 **0.785 N**），消除手向桌面施加的额外压力。开始松手前必须确认桌面已承接重量；松手全过程继续此载荷反馈。

释放时用每根手指的实测法向力反馈，令五指的目标载荷在 **1.5 s** 内平滑降到零，并继续跟踪 **1 s**，最后再用 **1 s** 完全张开。这能减小其余手指已脱离、拇指仍夹紧并向桌面下压的支撑转移尖峰。放桌和释放的逆运动学位置容差收紧为 **0.01 mm**，使微小的卸载指令及时执行。触觉切向力定义在指腹局部坐标系，板面或桌面法向反力也可能落在该指腹的切向平面；它不等于板擦与白板之间的摩擦力。

成功条件包括验证抬起、25 个单元残留归零、板擦在桌面自由稳定放置且手指载荷解除，并且执行期间没有求解器警告。单次演示的成功状态不构成随机场景成功率评估。

这些修正针对仿真接触与控制的数值问题。接触建立、滑动转向、支撑转移和松手仍会改变实际受力；验收同时检查原始力、接触受力中心和实际运动，而不以曲线越平越好作为目标。没有材料实验和真实传感器对照，仿真剩余变化不能直接解释为真实板擦的摩擦振动或触觉噪声。

## 与内存安装示例一致的结果目录

白板结果统一保存到 `datasets/erase_whiteboard_example`。正式示例使用与 `datasets/install_ram_example` 相同的六文件布局；命令先在临时目录完成采集、Raw 校验、视频完整解码和力分析，全部通过后再原子替换目标目录，不保留旧版：

```bash
pixi run record-whiteboard-example --compact --overwrite
```

共享 Raw HDF5 保存 **100 Hz** 状态、控制与未滤波触觉，以及 head、left_wrist、right_wrist 三路 **30 Hz、320×240** RGB。复核视频为 **10 fps**；四面板视频组合 head、right_wrist、右手五指法向触元和切向触元，固定全局视频从 HDF5 中保存的精确 `qpos` 离线渲染，不重新运行物理。

| 路径 | 内容 |
| --- | --- |
| `raw/erase_whiteboard_000000.h5` | 共享 Raw schema：状态、控制、三路 RGB、双手触觉、接触量和清洁累计量 |
| `raw/erase_whiteboard_000000.json` | Raw 校验、样本数、相机帧数、任务审计和 SHA-256 |

| `review/robot_global_short_path.mp4` | 保存状态的固定全局视角回放 |

力数据不滤波、不裁剪、不插值。Fn 是 35 个法向触元之和；曲线中的切向合力为指腹局部有符号 Fx/Fy 的 `hypot(Fx,Fy)`。只有显示热图的固定颜色量程可能饱和。`tactile_contact_force/*` 保存完整双手 10 指数据和顺序，保留有符号分量及坐标基。

HDF5 还保存世界坐标下的板面受力中心 `board_contact_center_world_m`、板面对板擦质心的合力矩 `board_contact_torque_world_nm`，以及 `board_contact_count`。受力中心按各接触点的法向载荷加权；无接触时这些量置零。

结果中的执行器指尖峰值按控制器统计，板面峰值按 **1000 Hz** 物理更新统计；示例力分析使用共享 Raw 中未滤波的 **100 Hz** 求解器触觉。清洁每 **1 ms** 更新。完整物理回归仍检查 1000 Hz 接触过程，不能只凭 100 Hz 曲线断言更高频的接触动力学已经收敛。

## 验证与本次结果

```bash
pixi run python -m pytest -q tests/test_whiteboard_cleaning.py tests/test_whiteboard_wipe.py tests/test_task_structure.py tests/test_scene_models.py tests/test_contact_tactile.py
```

检查覆盖白板倾角、共享相机一致性、扁平圆角板擦、显式摩擦接触对、初始桌面支撑、实际载荷/摩擦功/滑动门槛、重置和完整抓取—擦拭—放下流程。验证包括全程记录法向力与 `mj_step` 实际缓存力一致、擦拭承力建立后连续接触、持物稳定、下放时板擦相对手腕漂移小于 **2.5 mm**，以及桌面支撑全程峰值小于 **2 N**、下放/支撑/释放阶段的桌面峰值小于 **1.3 N**。

高频稳定性测试直接使用 **1000 Hz** 物理步接触解，分别检查抓取、提起、搬运、接近、移动加载、卸载、离板横移、稳定擦拭、下放、桌面支撑和释放阶段。每根手指的 Fn、切向合力及两个带符号切向分量，其相邻 **1 ms** 差值 RMS 在稳态与运动阶段须小于 **0.05 N**；接近和加载阶段使用 **0.08 N** 上限。同时检查连续承力状态下的板面受力中心和合力矩。

针对短时过冲，默认完整物理过程还要求：稳定 `wipe` 阶段板面法向峰值小于 **3.0 N**、拇指切向峰值小于 **1.3 N**；同一连续擦拭段相隔 **20 ms** 的板面法向变化小于 **0.7 N**、拇指切向变化小于 **0.28 N**。桌面支撑与释放阶段的拇指切向峰值须小于 **0.5 N**。共享 Raw 发布门槛另外要求五指全程峰值小于 **6 N**，稳定擦拭的相邻 10 ms Fn/Ft 变化都小于 **0.5 N**；全程核验没有直接手指碰板或对工具施加外力。

当前两条笔迹示例耗时 **57.10 s**，较早期 91.76 s 版本缩短约 **38%**；5712 个 100 Hz 状态样本和每路 1715 个 30 Hz 相机样本均通过共享 Raw 校验。1000 Hz 板面峰值为 **3.193 N**，发生在 35.93 s 的移动加载阶段；100 Hz 稳定擦拭板面峰值为 **2.348 N**。移动加载阶段相邻 10 ms 最大 Fn/Ft 变化为 **0.233/0.359 N**，稳定擦拭阶段为 **0.058/0.167 N**；全程最大 Fn/Ft 变化出现在约 7.86/8.70 s 的抓取阶段，而非擦板阶段。详见[执行与力分析结果](../../datasets/erase_whiteboard_example/raw/erase_whiteboard_000000.result.json)和[五指力曲线](../../datasets/erase_whiteboard_example/curves/right_hand_force_curves.png)。

新示例的 40±1 s 横跨第二条稳定擦拭和 `leave_board`，板面峰值 **2.344 N**，随后随离板动作归零；52±1 s 是主动 `release`，板面载荷为 0，五指 Fn 的下降与张手动作同步。整个过程在 57.10 s 结束，因此不存在 60 s 的异常段。两个展示视频均完整解码为 573 帧、57.3 s，且与同一 HDF5 时间轴同步。

## 统一采集与随机笔迹

已接入 [统一采集入口](../workflows/data_collection.md)，任务名 `whiteboard-wipe`；`--task all` 也会包含它。默认每条笔迹中心在板面中央局部方向 ±4 cm、±6 cm 随机平移，控制器用仿真已知中心调整实际擦拭轨迹。该能力不包括相机识别笔迹，也不保证整块板面边缘任意位置可达。单条示例默认仍固定位置，加 `--ink-seed` 才随机；统一采集加 `--fixed-stains` 可固定。

随机 seed、偏移和实际几何位置保存在 HDF5 和 result sidecar；离线视频恢复保存布局。当前笔迹为两条大范围笔画，随机平移范围保持不变；受力、摩擦功、滑动距离门槛不变。毛毡–白板 `solref` 从 0.02 s 调整为 0.09 s，以减小接触建立尖峰。这会改变接触力和轨迹分布，但不改变任务标识、相机、动作/观测、触觉语义或 Raw schema。

本轮重新运行了默认完整物理过程和随机范围角点过程，均完成抓起、两条擦净、放回及松手；清洁门槛、共享 Raw 采集/校验和相关转换接口测试也通过。这些有限样本不构成整板任意位置或任意 seed 必成功的保证。
