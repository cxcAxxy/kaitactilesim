当前版本已经加入被动接触件摩擦、真实底挡加载与卸载，见

新版保持正手抓取和肘部展开，并要求松手前连续确认主动触底。

运行原命令：

```bash
pixi run run-usb-insert
# 无窗口执行并保存报告（输出文件不能已经存在）

```

自动入口显式使用 `--run-task --plug-for-insertion`。沿用已认可正手版本的 USB 初态：标记朝下、yaw 为 330°，连接端朝机器人前方偏右。仅在 time=0 设置朝向，位置仍在原桌面位置；默认查看场景、旧 `--plug-face-down` 预设和其他任务保持原状。

末端抓取位置、手掌倾角及手指目标保留既有标定。取物时小拇指在远端，拇指和食指在近端；插入时掌心朝下，拇指和食指在上、小拇指在下。

```python
from kaihand_tactile_env.shared.simulation import ArmHandSimulation
from kaihand_tactile_env.tasks.usb_insert.setup import initialize_for_insertion
from kaihand_tactile_env.tasks.usb_insert.execution import UsbInsertionExecutor

sim = ArmHandSimulation(scene="usb-insert")
initialize_for_insertion(sim)  # reset 后、物理步进前
result = UsbInsertionExecutor(sim).execute()
print(result.success, result.failure_reason)
```
